Luồng Dữ liệu: Flat RAG vs GraphRAG

So sánh pipeline trích xuất vector thông thường và đồ thị tri thức liên kết ngữ nghĩa

Flat RAG (Vector Baseline)

Cosine Similarity · FAISS FlatIP

1

Chunking Văn bản

Chia tài liệu thành các đoạn cố định (220 words, 40 overlap).

2

Vector Embedding

Sử dụng sentence-transformers/all-MiniLM-L6-v2 tạo vector.

3

Vector Top-K Retrieval

Truy vấn Top-6 chunks tương đồng. Thường thất bại với multi-hop!

Hybrid GraphRAG (Production)

Neo4j · BFS Traversal · Provenance

1

NER + RE Extraction

Trích xuất quan hệ có cấu trúc strict JSON (Company, Person, Tech).

2

Entity Resolution & Cypher Ingest

Khử trùng lặp tên thực thể (Union-Find) và Bulk Ingest vào Neo4j.

3

Seed Matching & BFS Subgraph

Khám phá 2-hop lân cận, chặn Super-Nodes và tạo Hybrid Prompt.

Điểm mấu chốt: Flat RAG tìm kiếm theo "từ khóa/ngữ nghĩa gần", còn GraphRAG tìm kiếm theo "mối quan hệ bắc cầu giữa các thực thể". Khi câu hỏi đòi hỏi kết nối 2 bài báo khác nhau, chỉ GraphRAG mới xâu chuỗi được.

Module 1

Tiền xử lý & Coreference Resolution

Khử trùng lặp văn bản và giải quyết đại từ nhân xưng tránh tạo cạnh giả

Exact Dedup

Chuẩn hóa khoảng trắng & unicode NFKC. Tạo mã SHA-1 trên title + text để loại bỏ toàn bộ bài báo duplicate.

Rolling Chunking

Cắt văn bản theo rolling window: 220 từ/chunk, bước gối đầu (overlap) 40 từ để không bị đứt đoạn ngữ cảnh.

Conservative Coref

Chỉ thay "it", "they", "the company" thành tên entity khi tiền ngữ xuất hiện rõ ràng trong chunk. Nếu mơ hồ ➔ Giữ nguyên.

Python — Cell 1.7 Coreference Rule 
# Quy tắc Conservative: Tránh False Coreference
if confidence < 0.85 or is_ambiguous:
    unresolved_mentions.append(mention)
    return original_chunk_text  # Không ép thay thế để tránh hallucination
Module 2

Trích xuất Triples & Nạp Neo4j UNWIND

Thiết kế schema nghiêm ngặt và lưu vết nguồn gốc (Edge Provenance) 100%

Graph Schema Chuẩn

Node Labels: Company, Person, Technology (Base: Entity)

Allowed Relations: ACQUIRED, DEVELOPED, INVESTED_IN, FOUNDED, WORKED_AT, PARTNERED_WITH, USES, LEADS

Edge Provenance (Bắt buộc)

  • source_chunk_id: ID đoạn văn trích xuất.
  • published_date: Ngày xuất bản bài viết.
  • evidence: Câu văn làm bằng chứng thực tế.
  • confidence: Độ tin cậy (0.0 – 1.0).
Cypher — Cell 2.3 Bulk Ingestion (UNWIND Batch) 
UNWIND $rows AS row
MERGE (s:Entity {id: row.source_id})
  ON CREATE SET s.name = row.source_name, s.name_norm = row.source_norm
MERGE (t:Entity {id: row.target_id})
  ON CREATE SET t.name = row.target_name, t.name_norm = row.target_norm
MERGE (s)-[r:RELATION {type: row.relation, source_chunk_id: row.source_chunk_id}]->(t)
SET r.published_date = row.published_date, r.evidence = row.evidence, r.confidence = row.confidence
Module 3

Entity Resolution: Vector ANN + Lexical Guard

Hợp nhất các biến thể tên gọi thực thể mà không làm gộp nhầm

Cơ chế Hợp nhất (Union-Find)

1

Xóa Hậu tố Pháp lý

Loại bỏ "Inc", "Corp", "Ltd", "LLC" (ví dụ: "Apple Inc" ➔ "Apple").

2

Vector ANN Cosine Match

Tính cosine similarity giữa các embeddings (ngưỡng threshold = 0.88).

Lexical Guard (Chặn Gộp Sai)

Một số thực thể có vector embedding rất gần nhau nhưng là 2 đối tượng hoàn toàn khác nhau:

Ví dụ bị chặn:
• Apple vs Apple Music (Company vs Product)
• Google vs Google Cloud (Parent vs Sub-service)
Yêu cầu nộp bài: Xuất bảng entity_resolution_audit_df có ít nhất 10+ dòng ghi rõ: entity_a, entity_b, similarity_score, decision (MERGE / BLOCKED), reason.
Module 4

Hybrid Retrieval & Super-Node Mitigation

Trích xuất Seed Entity, duyệt đồ thị BFS và kiểm soát bùng nổ ngữ cảnh

1. Seed Entity Resolution

LLM trích xuất danh sách entity hạt nhân từ câu hỏi. Khớp chính xác trên Neo4j theo name_norm. Nếu không khớp ➔ fallback tìm kiếm vector similarity $\ge 0.66$.

2. Super-Node Policy

Các thực thể như Google, Microsoft có hàng nghìn liên kết (degree > 100).
Chính sách: Chỉ lấy tối đa 50 cạnh mới nhất theo published_date DESC. Giới hạn toàn context $\le 250$ edges.

Text — Linearized Subgraph Context Example 
Microsoft [Company] -INVESTED_IN-> OpenAI [Company] | date=2023-01-23 | chunk=art_01::c0002 | evidence=Microsoft invested $10 billion...
OpenAI [Company] -DEVELOPED-> GPT-4 [Technology] | date=2023-03-14 | chunk=art_04::c0010 | evidence=OpenAI officially launched GPT-4...
